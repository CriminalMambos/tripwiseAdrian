# TripWise

Proyecto final del curso: desarrollo de una web institucional estática en **HTML + SASS**.

## 📌 Objetivo
Sitio institucional de viajes con 5 páginas (index + 4 secundarias), estilos personalizados con SASS y diseño responsive.

## 🚀 Tecnologías
- HTML5 semántico
- SASS (partials, variables, mixins, nesting)
- Bootstrap adaptado a paleta propia
- Animaciones y transiciones

## 📂 Estructura
- `index.html`
- `/pages` (contacto, destinos, cotizador, nosotros, planificador)
- `/scss` (partials y main.scss)
- `/css` (main.css compilado)
- `/img` (imágenes del sitio)
